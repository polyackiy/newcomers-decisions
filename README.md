# Адаптация новичков

[Открыть приложение](https://tz2.pubrick.pro)

Тестовое задание «Новичок»: инструмент руководителя склада для разбора препятствий самостоятельной работе. Все 30 сотрудников и 63 записи вымышлены.

Записи → разбор AI с цитатами → решение руководителя → поручение → результат. Выводы можно уточнять, результат — исправлять, ситуацию — возвращать в работу; исходный разбор остаётся в истории.

Next.js, React, TypeScript, OpenAI Responses API (GPT-6.1 Terra). Расчёты выполняет код. Без API-ключа доступен сохранённый разбор; решения хранятся в браузере.

## Запуск

Node.js 24, npm.

```sh
npm ci
cp .env.example .env.local
npm run dev
```

Открыть http://localhost:3000. Для нового AI-разбора задать `OPENAI_API_KEY` и `AI_ENABLED=true` в `.env.local`. Ключ используется только на сервере.

Проверки: `npm test`, `npm run typecheck`, `npm run format:check`, `npm run build`.

Битрикс24: необязательный серверный `BITRIX24_WEBHOOK_URL` с правами на задачи. Без него работает предпросмотр. Синхронизации статусов нет; отправка на реальном портале не проверена.

Docker Compose: `deploy/compose.yml`, серверные переменные — `/etc/newcomers.env`. Для публичного запуска указать `APP_ORIGIN`; nginx — `deploy/nginx.conf`, HTTPS настраивается отдельно. Постоянный том хранит общий лимит AI-запросов.
